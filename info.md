## Oppo UDP-20x
Home Assistant integration for Oppo UDP-20x Blu-ray players (UDP-203 / UDP-205).

Actively-maintained fork of [`simbaja/ha_oppoudp`](https://github.com/simbaja/ha_oppoudp).
The domain (`oppo_udp`) is unchanged, so it installs as a drop-in replacement.

### Installation Notes

1. The Oppo UDP must be ON during setup so it can pass the connection test.
2. Set the player's standby mode to "Network Standby".
