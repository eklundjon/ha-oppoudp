# version it was built against. CI pins a specific PHACC per matrix job — a

# the latest for a quick dev loop:
#
#     python -m venv .venv
#     .venv/bin/pip install -r requirements.test.txt
#     .venv/bin/python -m pytest
#
pytest
pytest-asyncio
pytest-cov
pytest-homeassistant-custom-component

# Linter — pinned so local and CI agree. CI's lint job installs this exact pin

# cannot drift, and a Dependabot bump updates CI in the same PR.
